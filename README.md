# Structured-Programming-Practice
This repository contains 8 projects I have done and completed practicing for structured programming in C.

1. Basic Output; ref Ch.2 Exercise 2.16 program displays the sum, quotient, remainder and difference of two nmbers
2. Input-Output-Process; ref ch.2 Exercise 2.19 inputs three integers displays the sum, average, product, smallest and largest
3. Decision; ref ch.2 Exercise 2.24 describes the errors of a given code snippet
4. Basic Loop; ref ch.3 exercise 3.22 determines whether a number is prime or not
5. Loop with calculation; ref ch.4 exercise 4.12 prints a list of prime numbers from 1 to 100.
6. Loop with user input; ref ch.3 exercise 3.21 demonstrates the difference between pre-incrementing and post-incrementing
7. Loop with decision; ref ch.3 exercise 3.37 loops and displays multiples of five then displays the number of even numbers, odd numbers, and multiples of 5.
8. Interactive program; ref ch.3 exercise 3.18 prompts the user to either withdraw cash, deposit cash, check their balance or exit the system
